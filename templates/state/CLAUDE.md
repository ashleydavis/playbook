# State repo rules

This is the state repo. It tracks project state and lives outside the project repo so it stays consistent across worktrees. It holds the work-item queues (`work-items/`) and the `current-state.md` snapshot.

The spec lives in the project repo (`docs/spec/`). The process docs (`process.md`, `index.md`, `handbook.md`) and the work-item / queue rules (`work-items/CLAUDE.md`) live in the playbook, not here. This repo only holds project-specific state.

## Communication style
- Be simple and direct.
- Only give directly relevant information. No waffle.
- Use bullet points where possible.
- Keep it easy to understand.
